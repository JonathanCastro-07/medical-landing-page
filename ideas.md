# Brainstorming: Landing Page de Prontuário Médico

## Análise dos Sites de Referência

**Prontiva.com.br:**
- Design minimalista e limpo
- Paleta de cores suave (tons neutros com azul suave)
- Foco em confiança e segurança
- Seções bem estruturadas com call-to-actions claros
- Estatísticas de confiança destacadas

**CareSuite.com.br:**
- Design moderno e corporativo
- Paleta de cores profissional
- Ênfase em funcionalidades práticas
- Dashboard visual como elemento central
- Planos de preço transparentes

---

## Abordagem 1: Minimalismo Médico Contemporâneo
**Probabilidade: 0.08**

### Design Movement
Minimalismo Suíço aplicado ao healthcare digital — simplicidade extrema com hierarquia clara e espaçamento generoso.

### Core Principles
1. **Clareza acima de tudo** — cada elemento tem propósito, nada é decorativo
2. **Confiança através da transparência** — interface limpa comunica segurança
3. **Acessibilidade como prioridade** — contraste alto, tipografia legível, navegação intuitiva
4. **Espaço negativo como ferramenta** — respiro visual entre seções

### Color Philosophy
- **Primária:** Azul suave (`#4F8FD4` - azul médico calmo)
- **Secundária:** Verde menta (`#A8D8D8` - saúde e bem-estar)
- **Neutros:** Cinza claro (`#F5F7FA` - fundo), Cinza escuro (`#2C3E50` - texto)
- **Acentos:** Verde claro para CTAs positivas (`#6EC07A`)

**Intenção:** Transmitir profissionalismo, segurança e modernidade sem frieza

### Layout Paradigm
- Seções verticais com máxima largura de 1200px
- Alternância entre fundo branco e cinza claro para ritmo visual
- Alinhamento à esquerda para seções de texto, centralizado para CTAs
- Grid 12 colunas com gutters generosos (32px)

### Signature Elements
1. **Cards com sombra suave** — elevação sutil, sem bordas
2. **Ícones minimalistas em linha** — 2px stroke, 24px base
3. **Tipografia em duas camadas** — Display bold + Body regular

### Interaction Philosophy
- Transições suaves de 200ms em hover
- Escalas sutis (1.02x) em elementos interativos
- Feedback visual imediato mas discreto
- Sem animações desnecessárias

### Animation
- Fade-in de elementos ao scroll (200ms ease-out)
- Hover: scale(1.02) + shadow-lg em cards
- Botões: transform scale(0.98) ao clicar
- Nenhuma animação automática na página

### Typography System
- **Display:** Poppins Bold 48px (títulos principais)
- **Heading:** Poppins SemiBold 32px (subtítulos)
- **Body:** Inter Regular 16px (corpo de texto)
- **Small:** Inter Regular 14px (labels, captions)
- **Linha de altura:** 1.6 para corpo, 1.3 para títulos

## Abordagem 2: Wellness Moderno com Gradientes Suaves
**Probabilidade: 0.07**

### Design Movement
Design de bem-estar contemporâneo — inspirado em aplicativos de saúde premium (Headspace, Calm) com toques de glassmorphism.

### Core Principles
1. **Humanização da tecnologia** — design amigável que reduz ansiedade
2. **Movimento sutil** — animações que guiam a atenção naturalmente
3. **Profundidade através de camadas** — múltiplos planos visuais
4. **Cores que acalmam** — paleta baseada em tons naturais

### Color Philosophy
- **Primária:** Azul-verde suave (`#5BA3A3` - natureza calma)
- **Secundária:** Coral suave (`#E8B4A8` - humanidade, calor)
- **Terciária:** Lavanda (`#D4C5E2` - tranquilidade)
- **Neutros:** Branco puro (`#FFFFFF`), Cinza taupe (`#8B8680`)
- **Gradientes:** Azul-verde → Lavanda para fundos de seções

**Intenção:** Criar sensação de confiança, cuidado e modernidade

### Layout Paradigm
- Seções com altura variável (hero 100vh, outras 60-80vh)
- Uso de diagonais suaves (clip-path) para separar seções
- Imagens de fundo com overlay de gradiente
- Elementos flutuantes para criar profundidade

### Signature Elements
1. **Glassmorphism cards** — fundo semi-transparente com backdrop blur
2. **Gradientes de fundo** — transições suaves entre cores
3. **Ilustrações abstratas** — formas orgânicas em tons pastel

### Interaction Philosophy
- Parallax suave ao scroll
- Hover com mudança de cor + elevação
- Animações de entrada em cascata
- Micro-interações que deleitam

### Animation
- Parallax em imagens de fundo (velocidade 0.5x)
- Fade + slide-up ao scroll (300ms ease-out)
- Hover: color shift + shadow-xl em cards
- Pulse suave em CTAs (2s infinite)

### Typography System
- **Display:** Playfair Display Bold 52px (títulos elegantes)
- **Heading:** Poppins SemiBold 36px (subtítulos)
- **Body:** Lato Regular 16px (corpo, mais humanizado)
- **Small:** Lato Regular 14px (labels)
- **Linha de altura:** 1.7 para corpo, 1.2 para títulos

## Abordagem 3: Healthcare Futurista com Dados Visuais
**Probabilidade: 0.09**

### Design Movement
Tech-forward healthcare design — inspirado em dashboards de dados, interfaces de monitoramento, com toques de design de ficção científica acessível.

### Core Principles
1. **Dados como narrativa** — visualizações comunicam valor
2. **Precisão estética** — grid rigoroso, alinhamento perfeito
3. **Modernidade tecnológica** — sem parecer frio ou impessoal
4. **Interatividade implícita** — interface sugere que é explorável

### Color Philosophy
- **Primária:** Azul elétrico (`#2E7FD4` - tecnologia, confiança)
- **Secundária:** Ciano (`#00D9FF` - inovação, futuro)
- **Terciária:** Roxo suave (`#9B7FD4` - equilíbrio)
- **Neutros:** Cinza escuro (`#1A1F36`), Branco (`#F8FAFC`)
- **Acentos:** Ciano para dados positivos, Laranja para alertas

**Intenção:** Transmitir inovação, precisão e controle

### Layout Paradigm
- Grid 16 colunas com alinhamento rigoroso
- Seções com padrões geométricos de fundo
- Gráficos e visualizações como elementos centrais
- Asymmetria controlada para dinamismo

### Signature Elements
1. **Gráficos animados** — linhas que desenham ao scroll
2. **Padrões geométricos** — hexágonos, linhas, grids sutis
3. **Tipografia monoespacial** — números e dados em código

### Interaction Philosophy
- Interações que revelam dados
- Hover em elementos de dados mostra tooltips
- Cliques exploram funcionalidades
- Feedback visual detalhado

### Animation
- Gráficos desenham ao scroll (1s ease-in-out)
- Números contam ao scroll (1.5s)
- Hover: glow effect em elementos de dados
- Padrões de fundo animam sutilmente (20s linear)

### Typography System
- **Display:** IBM Plex Mono Bold 48px (títulos técnicos)
- **Heading:** Poppins SemiBold 36px (subtítulos)
- **Body:** IBM Plex Sans Regular 16px (corpo técnico)
- **Data:** IBM Plex Mono Regular 14px (números, dados)
- **Linha de altura:** 1.6 para corpo, 1.2 para títulos

---

## Decisão Final

Selecionada: **Abordagem 1 - Minimalismo Médico Contemporâneo**

**Justificativa:**
- Alinha-se com os sites de referência (Prontiva e CareSuite)
- Transmite confiança e segurança — crítico para healthcare
- Fácil de manter e escalar
- Acessibilidade natural através da simplicidade
- Performance superior (menos animações, menos assets)
- Comunica profissionalismo sem frieza

**Próximos passos:**
1. Implementar paleta de cores em `index.css`
2. Adicionar fontes (Poppins e Inter) no `index.html`
3. Criar componentes base com design system
4. Desenvolver seções da landing page
5. Gerar imagens para hero section
